# User Manual

## Customer
1. Register or sign in
2. Add a vehicle (VIN + registration)
3. File a claim with photos
4. Wait for AI assessment (damage, cost, fraud score)
5. Track status until surveyor decision / payment

## Surveyor
1. Sign in with surveyor account
2. Open queue of `surveyor_review` / `fraud_review` claims
3. Inspect AI detections and fraud signals
4. Approve with amount or reject with notes

## Accessibility
- Keyboard-focusable controls
- Dark/light mode toggle
- Reduced motion respected via CSS
